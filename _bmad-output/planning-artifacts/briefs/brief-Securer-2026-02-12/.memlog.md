- (event) brief run reconstructed from product-brief-Securer-2026-02-12.md during the v6.0.3 → v6.12.0 migration; entries below recover decisions the original artifact recorded
- (decision) product is self-hosted only for v1 — no SaaS instance; users must not have to trust a third party with credentials
- (decision) encryption happens server-side in memory using the sender-supplied password, not client-side WebCrypto — avoids key-derivation-in-JS and browser-compat complexity
- (decision) every secret is one-time view; expiration (1h/24h/7d) governs only the unclaimed shelf life, it is not an alternative mode
- (decision) access is two-factor by default: link plus password, so an intercepted link alone is worthless
- (decision) password-in-link convenience mode embeds the password in the URL fragment so the browser never transmits it — added for Dana's onboarding case, where a second channel per credential is unworkable
- (decision) all failure states (expired, viewed, burned, nonexistent) return one identical generic screen — no oracle about whether a secret ever existed
- (decision) limited password attempts (3-5) destroy the secret on exhaustion rather than locking it
- (decision) no accounts, no API, no admin UI in v1 — friction is the reason existing tools lose to Slack
- (decision) deployment target is a single docker-compose up with only port and database as configuration
- (direction) the adoption bar is speed: the flow must beat pasting into a Slack DM (~10 seconds) or the security properties do not matter
- (assumption) credential leaks via chat history are a leading breach vector — asserted from general security knowledge, not measured for this audience
- (decision) QR codes, syntax highlighting, countdown timer, About page and copy-with-message deferred out of v1 to protect the solo-developer timeline; recorded in addendum.md with reasoning, none rejected on merit
- (decision) moat is stated honestly as execution discipline (staying simple) rather than a fabricated technical moat — the primitives are all copyable
- (decision) text secrets only for v1, practical ceiling 10-50KB; file sharing deferred
- (event) brief finalized; addendum.md holds persona depth, adoption arc, deferral reasoning, risk register and carried-forward constraints
